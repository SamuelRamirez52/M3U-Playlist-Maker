About metadata

The library reads embedded tags and artwork locally when supported. Metadata and embedded artwork are read locally with TagLib-Wasm 2.5.0. Supported formats include MP3, AAC, M4A/MP4, FLAC, OGG, OPUS, WAV, AIFF, APE, DSF, DSDIFF and more. Available fields depend on the tags embedded in each file.

About M3U export

Playlists use relative paths from the selected music folder, for example:

#EXTM3U #EXTINF:-1,Track title Artist/Album/track.flac

Keep the same folder structure when transferring music and playlists to your device.
