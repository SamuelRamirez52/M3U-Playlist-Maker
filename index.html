About metadata

Nocturne can read and edit embedded tags and artwork locally with TagLib-Wasm 2.5.0. The metadata editor creates edited copies by default; batch edits export a ZIP. Original audio files are never overwritten by this version. Supported formats include MP3, AAC, M4A/MP4, FLAC, OGG, OPUS, WAV, AIFF, APE, DSF, DSDIFF and more. Available fields depend on the tags embedded in each file.

About M3U export

Playlists use relative paths from the selected music folder, for example:

#EXTM3U #EXTINF:-1,Track title Artist/Album/track.flac

Keep the same folder structure when transferring music and playlists to your device.

Local data

Playlists, library metadata and artwork cache are stored in this browser when storage is available. The first scan reads every file; later scans reuse unchanged metadata. Removing tracks never deletes source files.
