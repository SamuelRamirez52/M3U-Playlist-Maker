About

Nocturne M3U Manager is a browser-based music library manager designed to help you browse, organize and create M3U playlists from your local music collection.

Built with a focus on simplicity, privacy and customization, Nocturne processes your music library directly in your browser.

Features

- Music Library: Browse your collection by songs, albums, artists and genres.
- Metadata Reading: Read audio metadata using TagLib-Wasm.
- Album Artwork: Display embedded album covers.
- Playlist Manager: Create, organize and export M3U playlists.
- Sorting Options: Sort your library using different metadata fields, including release year.
- Custom Themes: Choose between Burgundy, AMOLED Black and Custom Color.
- Local Processing: Your music files are processed in your browser.

Supported Audio Formats

- FLAC
- MP3
- WAV
- APE
- M4A
- OGG
- DSD

Metadata availability may vary depending on the format and the individual file.

Getting Started

1. Open "Nocturne M3U Manager" (https://samuelramirez52.github.io/M3U-Playlist-Maker/).
2. Select your local music folder.
3. Let Nocturne scan your music library.
4. Browse your collection and create your playlists.
5. Export your playlists as M3U files.

Technology

- HTML, CSS and JavaScript
- "TagLib-Wasm" (https://github.com/taglib/taglib)
- Browser-based file access
- M3U playlist format
